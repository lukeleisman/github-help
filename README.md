# github-help

Notes I wrote while figuring out Git and GitHub, kept public in case they're useful to someone else.

## The pages

**getting-started.md** – How Git stores your work across workspace, index, local repository, and remote; installing Git and configuring your identity; generating an SSH key and adding it to your account and the ssh-agent; linking a local directory to a remote with `clone`, `init`, and `remote add`; the add / commit / push cycle and what each step is doing; getting other people's changes with `pull` versus `fetch` and `merge`; and a section on undoing things when they go wrong.

**commandsandworkflow.md** – The everyday status / add / commit / pull / push loop; working in a named branch and merging it back through a pull request, including cleaning up the branch afterward; opening an issue first and creating a branch from it so the branch name carries the issue number; and how to undo a local commit with `reset`.

**branchesandforks.md** – Forking versus branching and when each applies; creating, listing, and switching branches; and rescuing work you started on the wrong branch using `git stash`.
